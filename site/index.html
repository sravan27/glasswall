The wedge

Inventory tells you what exists. Patch-gap operations tells you what can burn you next.

Most tools optimize for compliance, breadth, or recurring update automation. Glasswall is built for the narrower moment that matters when exploit development gets faster: a fix is public, the patch diff is visible, and you need a queue that creates action now.

Adoption

Start where teams already live.

1. CLI

Scan a repo locally, build the remediation plan, and prove the queue before changing any workflow.

2. Actions

Emit SARIF, fail on urgency, and add remediation summaries to GitHub job pages that engineers already read.

3. GitHub App mode

Comment on pull requests, scan fork-safe heads, and open remediation branches from default-branch push events.

4. Pressure board

Turn saved history into fleet pressure, newly dangerous signals, and patch-gap MTTP instead of another backlog counter.
