Glasswall / Patch-Gap Operations

Public fixes should create pressure, not paperwork.

Glasswall ranks the window between public fix and real patching, then turns the result into a remediation queue that can live locally, in CI, and inside GitHub pull requests.

Local-first by default. GitHub App mode can mirror the same queue into pull requests.
